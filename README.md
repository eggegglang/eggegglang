# 蛋语言
蛋语言，中文编程语言，高智慧编程语言（简称蛋语），完全兼容C语言，高维度扩展了C语言，全新全优全功能面向对象范式！蛋语言，大道至简，遵行天道的高智慧编程语言。

【 概念定义 】

1. 蛋语言，简称蛋语。蛋语言倡导中文编程，不用英文缩写。“蛋”也象征圆满完美，C语言的“C”是缺口圆不完美，蛋语言高智慧高维度补全C语言使之圆满完美。
2. 蛋语言范（範），简称蛋范。比如说：开发一个蛋范，设计一个蛋范，做一个蛋范。范：模子，模板。蛋范不用“类”这个字，因为类与累谐音，不好听。
3. 蛋语言对象，简称蛋象，蛋范的运行实例。象：形状，样子，事物的外表形态。
4. 蛋语言库，简称蛋库，存放蛋范的仓库。
5. 蛋语言软件世界，简称蛋世界。
6. 蛋语言九大通用接口：打开，输入，输出，进出，交互零，交互一，交互二，交互三，关闭。九大接口对应实体的产生、吸收、释放、互相作用、消亡。这是天道，不是设计。
